# OEM Documentation

Python tools for working with Orbit Ephemeris Messages (OEMs).

## Getting Started

The `oem` package is available through Pip.

```bash
pip install oem
```

To create OEMs from TLEs with `sgp4` integration, install the `tle` extra.

```bash
pip install oem[tle]
```
